# 校园打印前端需求

学生先上传 PDF，自动进入打印预览，核对内容和规格后再填写学校账号提交。页面使用新野兽派设计，重点是实际文件和操作，不使用抽象宣传文案或装饰性大标题。

## 必要功能

- 上传前不要求登录，支持选文件和拖放。
- 预览实际 PDF 页面，显示真实页数，支持翻页、页码跳转、缩放及更换文件。
- A4 黑白预览与当前执行端的固定输出规格相对应。最终排版仍须由实际执行端和实体打印验证。
- 明确显示 A4、黑白、单面、单份、全部页面及纸张数量，不展示不能生效的设置。
- 点击确认打印后才填写学校账号；关闭确认框保留文件并清空密码。
- 上传、预览、确认提交三个步骤具有明确状态，服务离线不伪装成功。
- 保留真实任务记录、打印回执、未知结果查询和防重复提交。
- 仅本地预览，不因展示文档而上传内容。使用本地库与字体资源。

## 验收

检查多页与横向文档、真实画布内容、翻页、缩放、手机适配、无效或加密 PDF、50 页限制、文件替换竞态、密码清空、提交错误和重复请求。前端检查不能替代完整设备与实体打印验收。
