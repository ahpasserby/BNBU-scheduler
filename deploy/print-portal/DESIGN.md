# 打印入口设计与来源

## 当前方向

根据用户要求，打印入口采用 MAXCOURSE 现有的新野兽派与杂志编辑视觉。对照主工作区 `index.html` 的实际样式与首页渲染，沿用暖纸色 `#f4efe6`、墨黑 `#101820`、品牌绿 `#d6ff62`、衬线标题、Space Grotesk 正文和 IBM Plex Mono 小字。首页的章节编号与细分隔线用于页面层次，工具区的粗边框和硬阴影用于操作区。

版面由刊头、打印标题、文档区与学校账号区组成。文档区保持浅色，便于阅读文件名及输出规格；账号区使用深色和清楚的输入框，集中呈现验证与提交动作。绿色只用于标题标记、步骤标记与可提交的主按钮。

## 功能与状态

- 同一表单内选择 PDF，输入学号和密码，点击提交。账号验证、文件检查与提交依次执行，密码只填写一次。
- 文档区分别设计空白、文件已选择、读取中、校验失败状态，支持查看本地文件及移除。所选文件名使用真实文本，不展示样例文档。
- 固定规格按纸张、颜色、单双面、份数列出，实际支持 A4、黑白、单面、单份。最多 10 MB、50 页，不加入未实现的参数选择器。
- 顶部状态读取实际接口。服务离线时禁止提交，仍可查看页面及选择文件。
- 提交结果以独立打印回执呈现。成功表示进入学校队列，仍需刷卡释放。结果不明时先查询，不自动重发。
- 仅有本人记录时显示最近打印，默认折叠。打印须知保留在弹窗中。

## 设计来源与验收

前两轮基础界面由本机 Kimi CLI 的 `kimi-code/k3` 以 `thinking.effort=max` 设计，调用后已恢复原默认强度。本轮根据用户新指定的品牌方向，由主任务对照现有 MAXCOURSE 页面重做 HTML 和 CSS，保留已验证的提交流程。

使用本地 UI/UX Pro Max 的新野兽派及可访问性参考，并通过 Playwright 检查实际浏览器。无远程字体、CDN 或新增框架。需要覆盖桌面与手机、文件选择、账号验证错误、离线、提交回执、重复点击及结果不明后的查询。
