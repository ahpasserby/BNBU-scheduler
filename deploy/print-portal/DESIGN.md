# 校园打印界面与功能

## 当前设计

按用户反馈（荧光绿与米色组合显得廉价），第二轮改为可切换的配色系统，用户从三个方向中选择了“墨与纸”与“暗房”随系统外观自动切换：

- 浅色（墨与纸）：暖白纸色背景、白色卡片、墨黑文字与主按钮，点缀色为低饱和的蓝黑墨水色，只用于扫描光、选中状态、成功回执与焦点。
- 深色（暗房）：系统开启深色模式时，界面变为石墨色，预览区像灯箱一样让白纸发光，点缀色为香槟金，主按钮反白。

两套配色由同一组颜色变量驱动，回执小票和纸张在两种外观下都保持白纸。字体统一使用系统字体（苹方、SF、Segoe UI、微软雅黑），数字使用等宽数字；Space Grotesk 只保留在 MAXCOURSE 字标上。去掉了荧光绿、点阵背景、按钮中的圆形箭头与扫光，标题字重和圆角也更克制。

流程仍为“上传文档 → 预览与设置 → 确认提交”，所有动画都用来解释打印结果，而不是装饰：

1. 上传：一叠纸张随指针轻微倾斜，拖入文件时散开，标题切换为“松开，即可预览”。整页都接受拖放，拖偏也不会离开页面。
2. 进入预览：支持视图过渡的浏览器中，上传区的纸张直接放大成预览页；其余浏览器直接切换。
3. 设置联动预览：切换彩色时一道扫描光从左到右把页面染成彩色；选择双面后纸张自动翻面演示一次，长边沿竖轴、短边沿横轴翻转，背面显示真实的下一页；份数增加时后方叠出对应数量的纸张并显示份数角标；合计张数滚动变化。
4. 确认提交：弹窗带背景模糊与弹性进场，手机上为底部面板。提交时账号输入收起，显示“验证账号、检查文件、送往队列”三步进度，缩略图上有扫描光带。
5. 回执：一张小票从打印机出纸口分段送出，随后勾选图标描边、明细逐行出现。失败轻微抖动，结果待确认时指示灯闪烁。

右栏在桌面端吸顶：设置为“标签在左、控件在右”的紧凑行，下方为合计与确认按钮，1440×900 首屏即可看到确认按钮。手机端结算栏吸底，预览工具栏移到预览区顶部避免被遮挡。系统开启减少动态效果时，所有动画和视图过渡关闭。

## 打印选项

颜色（黑白 / 彩色）、单双面（单面 / 双面，双面再选长边或短边翻页）、份数（1–20，单次最多 200 面）。选项是否可用取决于执行端声明的能力；设备未声明时对应选项禁用并注明“设备暂不支持”，离线时仍可在本地预览全部选项，恢复连接后自动回到设备支持的规格。结果不确定时沿用原任务的编号与选项，不允许修改。

## 参考与取舍

- [FedEx Office Copies & Custom Documents](https://www.office.fedex.com/default/copies.html)：文件优先、规格集中、提交前核对。装订与纸张选项不属于本服务能力，未照搬。
- [PaperCut Web Print](https://www.papercut.com/tour/web-print/)：网页提交到学校队列，不把提交成功表述为已出纸。
- 常见打印预览窗口：文档与规格并排，翻页与缩放靠近文档，最后提交。

## 实现与设计来源

预览使用本地固定版本的 Mozilla PDF.js 6.3.289，先离屏绘制再替换画布，翻页与缩放不闪白。彩色扫描、翻面和叠纸均为 CSS 与 Web Animations 实现，没有新增前端依赖。本轮界面与动画由主任务按用户最新要求重做。
