# 打印入口设计与来源

视觉和前端初稿由本机 Kimi CLI 的 `kimi-code/k3` 完成，调用时 `thinking.effort=max`。已核对该模型支持 low、high、max，调用结束后恢复原有默认强度。Kimi 产出了 HTML、CSS 和前端交互初稿；主任务随后负责接口联调、错误处理、幂等提交、可访问性和真实浏览器验收。

## 视觉

暖纸色背景，石墨色文字，宋体中文标题，窄幅单列编辑排版。用细分隔线和小号步骤编号建立层级，只在品牌与状态上使用少量绿色。文档上传是唯一主操作，不堆叠装饰卡片、统计数字或无功能的设置。

## 交互

先选 PDF，检查实际页数，再填写本次学校密码。固定 A4、黑白、单面、单份，用摘要呈现而非伪选项。异常状态直接放在文件、密码或任务旁边。已提交的结果以学校队列为边界，明确需要刷卡取件。

离线时仍可了解流程，但无法检查或提交文件。演示环境持续显示“不真实打印”。重复点击立即禁用；网络结果不明时保留原任务编号，用查询或同编号重试避免重复提交。更换文件会取消旧检查，旧 FileReader 和请求结果都不能覆盖新文件。

## 验收范围

需在桌面与 375px 手机视口检查溢出、键盘焦点、表单标签、密码清空、上传替换、离线状态和未知结果恢复。真实设备网络恢复后，另行验证网页提交到本人刷卡队列，不能以本地演示替代。
