# 打印入口设计与来源

## 当前方向

根据用户对上一版页面凌乱的反馈，重做为单个打印工作区。桌面左侧选择文件，右侧填写学号和密码；手机端自然堆叠。账号验证、PDF 检查与提交由同一次操作串联，学生只输入一次密码。

背景为浅中性色，主面板为白色，采用清晰的无衬线中文字体与少量品牌绿色。主页面保留一个标题、一个表单和简短页脚。打印须知收进弹窗，最近打印仅在有本人真实记录时出现，默认折叠。A4、黑白、单面、单份为实际支持的固定规格。

不显示演示身份、预置任务或虚构成功。页面始终读取正式 API 的连接状态，设备未连接时不能提交。只有学校队列返回确定回执时展示取件提示，不把队列提交解释成已出纸。无法确认结果的任务保留原编号，查询不会重新发送。

## 设计来源

两轮视觉设计均调用本机 Kimi CLI 的 `kimi-code/k3`，设置 `thinking.effort=max`。本轮由 Kimi 重做 HTML 与 CSS，主任务负责真实接口衔接、一次填写的提交流程、竞态处理、浏览器检查及最终调整。调用后恢复用户原有默认强度。

设计与验收使用本地 UI/UX Pro Max 和 Playwright 工作流，不引入远程字体或 CDN。验收范围包括桌面、375px 手机布局、键盘访问、错误提示、文件替换、重复提交、未知结果恢复和账号切换。
