# 校园打印界面与功能

## 当前设计

以线上布局为基础，视觉改为 MAXCOURSE 主站的杂志风格加新野兽派工具面板，与首页目录中的第 VIII 章“校园打印”保持一致。

- 杂志部分：页头使用与首页相同的衬线字标“Maxcourse / CAMPUS TOOLKIT”；章节以斜体衬线“VIII. Campus Printing”开头，标题使用宋体系衬线；规格、页码等小字使用 IBM Plex Mono；纸色背景带浅网格，章节下方是一条墨线。
- 新野兽派部分：上传区、预览、设置、合计、对话框、记录均为方角、粗墨线边框与硬投影；按钮悬停上浮、按下时连同投影压下；选中态与主按钮使用品牌荧光绿 `#d6ff62`，离线等状态用品红点缀。
- 配色只保留浅色，与主站一致：纸色 `#f4efe6`、墨色 `#101820`、荧光绿 `#d6ff62`。

流程为“上传文档 → 预览与设置 → 确认提交”。动画用来解释打印结果：上传区纸张随指针倾斜、拖入时散开并在支持视图过渡的浏览器中放大成预览页；切换彩色时荧光绿扫描线把页面染色；双面时纸张沿长边或短边翻面并显示真实背面；份数增加时后方叠出带墨线的纸张；提交时显示分步进度；回执小票从打印机逐格送出，锯齿边带硬投影，勾选图标盖章式出现。系统开启减少动态效果时全部关闭。

## 打印选项与文件

颜色（黑白 / 彩色）、单双面（单面 / 双面，双面再选长边或短边翻页）、份数（1–20，单次最多 200 面）。选项是否可用取决于执行端声明的能力；设备未声明时对应选项禁用并划线。

支持 PDF、Word、PPT、Excel、OpenDocument、RTF 与 JPG/PNG。非 PDF 文件先在打印设备上转换为 PDF，再进入同样的预览与提交流程；文件卡片显示原扩展名与“已转为 PDF”。设备未声明转换能力时只接受 PDF。

## 参考与取舍

- MAXCOURSE 首页：衬线字标、斜体罗马数字目录、等宽字母间距标签、细墨线与纸色网格背景。
- [FedEx Office Copies & Custom Documents](https://www.office.fedex.com/default/copies.html)：文件优先、规格集中、提交前核对。
- [PaperCut Web Print](https://www.papercut.com/tour/web-print/)：网页提交到学校队列，不把提交成功表述为已出纸。

## 实现与设计来源

预览使用本地固定版本的 Mozilla PDF.js 6.3.289，先离屏绘制再替换画布。彩色扫描、翻面、叠纸与出纸均为 CSS 与 Web Animations 实现，没有新增前端依赖。用户在多轮本地方案后选择以线上版本为基础改为新野兽派加杂志风格；此前本地的介绍页与校样方案未上线，已舍弃。
